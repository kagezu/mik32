# Библиотека Display

Для подключения необходимо в файле **config.h** выбрать необходимые опции.
Желательно скопировать [config.h](template/config.h) в свою директорию, что позволит иметь отдельную конфигурацию для каждой сборки.

## Настраиваемые опции

### Варианты подключения

Выбор пинов и накладываемые ограничения зависит от драйвера и интерфейса.
Используемые пины по умолчанию можно посмотреть в файле pins.h соответствущего драйвера.

### Класс дисплея

Можно создать несколько объектов дисплеев, для нескольких дисплеев или если есть необходимость в использовании нескольких цветовых режимов:

Display< **драйвер** <**RGB тип**>, **RGB тип**, **Тип поворота**> **Имя**;

Пример:

```с++
  Display < ST7735_SPI<RGB32>, RGB32> lcd18;
  Display < ST7735_SPI<RGB16>, RGB16> lcd16;

  lcd16.init();
  // тут можно использовать 65k цветов
  lcd18.init();
  // теперь можно использовать 262к цветов
```
