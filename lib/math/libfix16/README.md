# libfix16

Извлечено из репозитория SVN libfixmath на Google Code.
Libfix16 реализует операции с фиксированной точкой формата Q16.16 в C.

Лицензия: <a href="http://www.opensource.org/licenses/mit-license.php">MIT</a>

Библиотека оптимизирована для RV32IMC

## Параметры

Параметры конфигурации — это определения компиляции, которые проверяются препроцессором с помощью `#ifdef` и `#ifndef`. Все они по умолчанию не определены.

#### `FIXMATH_FAST_SIN`

- `#ifndef`: самая точная версия, точность ~2,1%.
- `#ifdef`: быстрая реализация, работает на 159% быстрее, чем вышеприведенная «точная» версия, с немного меньшей точностью ~2,3%.

#### `FIXMATH_NO_OVERFLOW`

- `#ifndef`: Проверка на переполнение и возврат констант переполнения.
- `#ifdef`: Не проверять на переполнение.

#### `FIXMATH_NO_ROUNDING`

- `#ifndef`: Использовать округление.
- `#ifdef`: Не использовать округление.
