# libfixmath

Извлечено из репозитория SVN libfixmath на Google Code.
Libfixmath реализует операции с фиксированной точкой формата Q16.16 в C.

Лицензия: <a href="http://www.opensource.org/licenses/mit-license.php">MIT</a>

Библиотека будет оптимизирована для RV32IMC

## Параметры

Параметры конфигурации — это определения компиляции, которые проверяются препроцессором с помощью `#ifdef` и `#ifndef`. Все они по умолчанию не определены.

#### `FIXMATH_FAST_SIN`

- `#ifndef`: самая точная версия, точность ~2,1%.
- `#ifdef`: быстрая реализация, работает на 159% быстрее, чем вышеприведенная «точная» версия, с немного меньшей точностью ~2,3%.

#### `FIXMATH_NO_64BIT`

- `#ifndef`: Для компиляторов/платформ, которые имеют `uint64_t`.
- `#ifdef`: Для компиляторов/платформ, которые не имеют `uint64_t`.

#### `FIXMATH_NO_CACHE`

- `#ifndef`: Использовать кэши статической памяти для экспонент (32 КБ) и тригонометрии (80 КБ).
- `#ifdef`: Не использовать кэши.

#### `FIXMATH_NO_HARD_DIVISION`

Примечание: будет автоматически определено, если определено `FIXMATH_OPTIMIZE_8BIT`.

- `#ifndef`: Для платформ, которые имеют аппаратное целочисленное деление.
- `#ifdef`: Для платформ, которые не имеют аппаратного целочисленного деления.

#### `FIXMATH_NO_OVERFLOW`

- `#ifndef`: Проверка на переполнение и возврат констант переполнения.
- `#ifdef`: Не проверять на переполнение.

#### `FIXMATH_NO_ROUNDING`

- `#ifndef`: Использовать округление.
- `#ifdef`: Не использовать округление.

#### `FIXMATH_OPTIMIZE_8BIT`

- `#ifndef`: Не оптимизировать для процессоров с 8-битным умножением, таких как Atmel AVR.
- `#ifdef`: Оптимизировать для процессоров, таких как Atmel AVR. Также автоматически определяет `FIXMATH_NO_HARD_DIVISION` в `fix16.h`.
