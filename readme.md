# Песочница для ATmega и MIK32 AMUR

## ![alt text](./tools/img/ace-uno.jpg)

### MK / Платы

+ **ATmega328P / Uno R3 - 16...27 МГц**
+ **MIK32 AMUR / ACE UNO**

### Дисплеи

+ **ST7735**
  + Программно
  + SPI
+ **ILI9225**
  + Программно
  + SPI
+ **ST7789**
  + 8 bit
+ **ILI9486**
  + 8 bit
  + 16 bit
+ **NT35510**
  + 16 bit
